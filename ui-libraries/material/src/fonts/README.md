# Bundled fonts

Variable fonts bundled for the Material library, imported into `.slint` files
and registered at runtime.

## google-sans-flex

`GoogleSansFlex[GRAD,ROND,opsz,slnt,wdth,wght].ttf` — byte-identical copy of
`ofl/googlesansflex/` in the `google/fonts` repository
(upstream: <https://github.com/googlefonts/googlesans-flex>), pinned at commit
`3dc14e61f108f036db84188b9b405a67df9b7c88` (git blob sha
`32fa9a00044d11fa226b39159e4907d9a16245c8`). Axes: `opsz` 6–144, `wdth`
25–151, `wght` 1–1000, `GRAD` 0–100, `ROND` 0–100, `slnt` −10–0.

Licensed under OFL-1.1 with no Reserved Font Names — see `OFL.txt` and
`TRADEMARKS.md`.
