`SwipeToDismissBoxValue`

 This enum is used to define the anchor state of a `SwipeToDismissBox`.

* **`start-to-end`**:  The box is dismissed towards the end edge.
* **`end-to-start`**:  The box is dismissed towards the start edge.
* **`settled`**:  The box rests in place, not dismissed.
