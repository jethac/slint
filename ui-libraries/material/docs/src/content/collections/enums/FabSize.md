`FabSize`

This enum selects the container size of a `FloatingActionButton` — the
M3E FAB size set.

* **`small`**: The 40px small FAB; deprecated upstream styling, kept for compatibility.
* **`baseline`**: The default 56px FAB.
* **`medium`**: The 80px medium FAB.
* **`large`**: The 96px large FAB.
