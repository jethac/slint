`PullToRefreshIndicatorKind`

 This enum is used to select the indicator a `PullToRefreshBox` draws while pulled.

* **`classic`**:  The 40dp surface box crossfading a pull arrow to a circular spinner.
* **`loading-indicator`**:  The 48dp contained loading indicator.
* **`none`**:  No built-in indicator, for custom `PullToRefreshIndicatorBox` content.
