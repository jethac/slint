`ExtendedFabSize`

This enum selects the container size of an `ExtendedFloatingActionButton`.

* **`small`**: The 56px small extended FAB.
* **`baseline`**: The default extended FAB.
* **`medium`**: The 80px medium extended FAB.
* **`large`**: The 96px large extended FAB.
