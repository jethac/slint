`MaterialButtonSize`

This enum selects the size bucket of a button or icon button.
Each bucket sets the container height, padding, icon size, and label type role.

* **`extra-small`**: A 32px container for dense surfaces.
* **`small`**: A 40px container; the default size.
* **`medium`**: A 56px container for prominent actions.
* **`large`**: A 96px container.
* **`extra-large`**: A 136px container for hero actions.
