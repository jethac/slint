`MenuGroup`

One `DropdownMenuGroup` in a menu's `groups` model — an optional group label plus its items, drawn on the group's own container surface.

- **`label`** (_string_): The `DropdownMenuGroupLabel` text shown above the group's items.
- **`items`** (_[MenuItem]_): The group's menu items.
