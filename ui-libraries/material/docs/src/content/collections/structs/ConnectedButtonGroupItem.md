`ConnectedButtonGroupItem`

This structure represents an item in a connected button group.

- **`icon`** (_image_): The icon to display for the item.
- **`checked-icon`** (_image_): The icon to display for the item while checked.
- **`text`** (_string_): The text label for the item.
- **`tooltip`** (_string_): The tooltip shown on hover.
- **`disabled`** (_bool_): Whether the item is disabled.
- **`checked`** (_bool_): The item's checked state for multi-select groups.
