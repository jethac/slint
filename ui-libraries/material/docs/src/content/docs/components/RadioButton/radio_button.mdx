`RadioButton`s let people select one option from a set of options. The control is a 20px
stroked circle centered in its padding; the dot's radius springs to 6px on selection and a
focused button shows the circular inset ring while hover or press draws the 40px
state-layer circle. Selecting is the parent's job — `checked` is an input the surrounding
group rebinds when another option is picked.

## Properties

### checked
<SlintProperty propName="checked" typeName="bool" propertyVisibility="in">
Whether the radiobutton is checked.
</SlintProperty>

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
Whether the radiobutton is enabled and can be interacted with.
</SlintProperty>

### enforce-touch-target
<SlintProperty propName="enforce-touch-target" typeName="bool" defaultValue="true">
Whether the radiobutton extends its touch target to at least 48px when its visual container is smaller.
</SlintProperty>

## Callbacks

### clicked()
Invoked when the radiobutton is clicked.
