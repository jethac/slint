`MaterialText` renders text in one of the Material 3 type-scale roles. It inherits the `Text` element, so every `Text` property and callback applies; the `style` property selects the role — font family, size, weight, tracking, and line height come from the generated type tokens. With no `style` it renders `body_large`, matching Compose's `LocalTextStyle` default.

<CodeSnippetMD imagePath="/src/assets/generated/text-roles.png" scale="3" imageWidth="300" imageHeight="200" imageAlt="" needsBackground="true">
```slint
import { MaterialText, MaterialTypography } from "@material";
export component Example inherits Window {
    width: 300px;
    height: 200px;
    background: transparent;
    VerticalLayout {
        padding: 8px;
        MaterialText {
            text: "Headline small";
            style: MaterialTypography.headline_small;
        }
        MaterialText {
            text: "Body large";
            style: MaterialTypography.body_large;
        }
        MaterialText {
            text: "Label medium emphasized";
            style: MaterialTypography.label_medium_emphasized;
        }
    }
}
```
</CodeSnippetMD>

## Properties

### style
<SlintProperty propName="style" typeName="struct" structName="MaterialTypeStyle" defaultValue="MaterialTypography.body_large">
The type-scale role to render with, taken from `MaterialTypography`. Every role in the Material 3 type scale is available — `display_large/medium/small`, `headline_large/medium/small`, `title_large/medium/small`, `body_large/medium/small`, `label_large/medium/small` — and each has an `*_emphasized` variant that uses the emphasized (medium-weight) tokens.

```slint "style: MaterialTypography.headline_medium;"
MaterialText {
    text: "Settings";
    style: MaterialTypography.headline_medium;
}
```
</SlintProperty>

### color
<SlintProperty propName="color" typeName="brush" defaultValue="MaterialPalette.on_background">
The text color. Defaults to `MaterialPalette.on_background`; set it explicitly to a palette role such as `MaterialPalette.primary` or `MaterialPalette.on_surface_variant` for colored or secondary text.
</SlintProperty>

All other `Text` properties — `font-family`, `font-size`, `font-weight`, `letter-spacing`, `line-height`, `wrap`, `overflow`, `max-lines`, `min-lines`, `font-underline`, `font-strikeout`, `horizontal-alignment`, `vertical-alignment` — are inherited from `Text` and can be set directly.
