A `ButtonGroup` displays a set of related buttons as a single control. Pressing a
button makes it grow while its neighbors shrink by an equal amount, animated with a
fast spatial spring. When the group does not fit its available width, overflowing
items collapse into a "More options" menu.

## Properties

### items
<SlintProperty propName="items" typeName="[struct]" structName="ButtonGroupItem">
An array of group items. Each item has `text`, an optional leading `icon`,
`checked`/`enabled`/`weight`/`alignment`/`compression-limit`, and fields the
component writes back with the item's resolved geometry.
</SlintProperty>

### selection
<SlintProperty propName="selection" typeName="enum" enumName="ButtonGroupSelection">
`none` (default): plain buttons. `single`: checking an item unchecks the others;
`current-index` tracks the selected item. `multiple`: items toggle independently.
</SlintProperty>

### current-index
<SlintProperty propName="current-index" typeName="int" propertyVisibility="in-out">
The index of the currently selected item (`single` selection), -1 when none.
</SlintProperty>

### expanded-ratio
<SlintProperty propName="expanded-ratio" typeName="float">
Fraction of the pressed item's own width it may grow by, `0.15` by default.
</SlintProperty>

### spacing
<SlintProperty propName="spacing" typeName="length">
Space between adjacent items, `12px` by default.
</SlintProperty>

### vertical-alignment
<SlintProperty propName="vertical-alignment" typeName="enum" enumName="ButtonGroupItemAlignment">
Vertical alignment of items whose `alignment` is `inherit`: `top` (default),
`center`, or `bottom`.
</SlintProperty>

### size
<SlintProperty propName="size" typeName="enum" enumName="MaterialButtonSize">
The size bucket of every item in the group.
</SlintProperty>

### button-shape
<SlintProperty propName="button-shape" typeName="enum" enumName="MaterialButtonShape">
`round` (default) or `square` resting shape.
</SlintProperty>

### overflow-icon / overflow-tooltip
<SlintProperty propName="overflow-icon" typeName="image">
The icon and tooltip of the overflow indicator shown when items do not fit.
</SlintProperty>

## Callbacks

Set `selection-on-click: false` when the application owns checked state or `current-index`.
Row buttons and overflow menu items request the same state change without writing the bound selection.
The application can accept or reject requests.
The default updates group state before invoking callbacks.
Controlled single selection uses `current-index` as its source; activating its selected item requests `-1` to deselect it.
Default single selection also synchronizes the model's checked flags and selected index.
Multiple selection uses each model row's checked flag.
Programmatic changes emit neither selection callback.
Disabled controls ignore activation.

```slint
import { ButtonGroup, ButtonGroupSelection } from "@material";

export component Example inherits Window {
    width: 300px;
    height: 100px;
    in-out property <int> selected: 0;
    ButtonGroup {
        items: [{ text: "First" }, { text: "Second" }];
        selection: ButtonGroupSelection.single;
        current-index: root.selected;
        selection-on-click: false;
        current-index-changed(index) => { root.selected = index; }
    }
}
```

### current-index-changed(index: int)
Requests the selected index in single-selection mode, or `-1` to deselect.

### item-checked-changed(index: int, checked: bool)
Requests an item's checked state in single- or multiple-selection mode.
Use a writable model when the group owns selection.

### activated(index: int)
Invoked after an enabled row or menu item requests selection.
Plain clickable items invoke only this callback.

## Functions

### select(index: int)
Selects the item at `index` in `single` selection mode.
