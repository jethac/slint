---
title: Toggle buttons
description: Text and icon buttons with checked state and checkbox semantics.
---

Use a toggle button for an action with a persistent checked state.
Pointer clicks, Space, Enter, and the accessibility default action change `checked` and invoke `clicked` once.
Disabled controls ignore activation.
Space and Enter activate on release.
Moving focus away or disabling a control cancels its pending keyboard press.
Repeated key-down events keep the pressed state without producing extra clicks.

```slint
import { ToggleButton, FilledTonalIconToggleButton } from "@material";

export component Example inherits Window {
    width: 300px;
    height: 100px;
    HorizontalLayout {
        ToggleButton { text: "Follow"; checked: true; }
        FilledTonalIconToggleButton { tooltip: "Pin"; }
    }
}
```

The named toggle components expose the checkbox accessibility role.
Text buttons use `text` as their accessible name, falling back to `tooltip` when the text is empty.
Icon buttons use `tooltip` as their accessible name.
Give every icon toggle a descriptive tooltip.

| Component | Styling and inherited properties |
| --- | --- |
| `ToggleButton` | `FilledButton` |
| `FilledTonalToggleButton` | `TonalButton` |
| `ElevatedToggleButton` | `ElevatedButton` |
| `OutlinedToggleButton` | `OutlineButton` |
| `IconToggleButton` | `IconButton` |
| `FilledIconToggleButton` | `FilledIconButton` |
| `FilledTonalIconToggleButton` | `TonalIconButton` |
| `OutlinedIconToggleButton` | `OutlineIconButton` |

All eight components default to `checkable: true` and `checked: false`.
They inherit size, shape, enabled state, and motion behavior from their corresponding button style.
All four text variants expose `padding-leading`, `padding-trailing`, and `padding-vertical` overrides.
Icon variants also inherit `icon` and `checked-icon`.
Use `checked` to observe or set the current state.
Keep `checkable` enabled when using a named toggle component.

Set `container-color` and `content-color` for the unchecked state, and `checked-container-color` and `checked-content-color` for the checked state.
Use `disabled-container-color` and `disabled-content-color` for disabled controls, including their alpha.
The standard icon variant also retains its `has-error` and `inverse` color modes.

Set `resting-radius`, `pressed-radius`, and `checked-radius` to override uniform corners.
Set `elevation-default`, `elevation-pressed`, `elevation-hovered`, `elevation-focused`, and `elevation-disabled` in logical pixels.
These accept fractional values such as `2.5px`.
Use `border-width`, `checked-border-width`, `border-color`, and `disabled-border-color` to customize borders.
The default checked border width is zero.

Place custom children inside any variant to add content to its centered row.
Text and icon properties can be combined with custom children.
The container grows to fit content and padding while preserving the minimum touch target.
