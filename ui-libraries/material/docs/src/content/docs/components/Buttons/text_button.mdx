A `TextButton` is a button with no container or border, only a label.
Use it for the lowest-emphasis actions such as dismissals in dialogs.

<CodeSnippetMD imagePath="/src/assets/generated/textbutton-sizes.png" scale="3" imageWidth="940" imageHeight="460" imageAlt="">
```slint
import { TextButton, MaterialButtonSize, MaterialButtonShape } from "@material";
export component Example inherits Window {

    }
}
```

## Properties

### button-shape
<SlintProperty propName="button-shape" typeName="enum" enumName="MaterialButtonShape" defaultValue="MaterialButtonShape.round">
The resting container shape: `round` for the fully rounded stadium, `square` for the smaller rounded corner.
</SlintProperty>

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
Whether the button is enabled and can be interacted with.
</SlintProperty>

### enforce-touch-target
<SlintProperty propName="enforce-touch-target" typeName="bool" defaultValue="true">
Whether the button extends its touch target to at least 48px when its visual container is smaller.
</SlintProperty>

### icon
<SlintProperty propName="icon" typeName="image">
An optional icon displayed before the text label.
</SlintProperty>
### inverse
<SlintProperty propName="inverse" typeName="bool">
Whether to use the inverse color scheme for the button.
</SlintProperty>


### size
<SlintProperty propName="size" typeName="enum" enumName="MaterialButtonSize" defaultValue="MaterialButtonSize.small">
The size bucket, from `extra-small` (32px) through `extra-large` (136px).
</SlintProperty>

### text
<SlintProperty propName="text" typeName="string">
The text label displayed on the button.
</SlintProperty>

### tooltip
<SlintProperty propName="tooltip" typeName="string">
A tooltip text that appears when hovering over the button.
</SlintProperty>

## Callbacks

### clicked()
Invoked when the button is clicked.
