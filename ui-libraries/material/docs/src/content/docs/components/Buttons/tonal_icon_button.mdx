A `TonalIconButton` is an icon button with a tonal container color.
Set `checkable` and the button springs between its resting shape and its selected shape whenever `checked` changes.

## Properties

### button-shape
<SlintProperty propName="button-shape" typeName="enum" enumName="MaterialButtonShape" defaultValue="MaterialButtonShape.round">
The resting container shape: `round` for the fully rounded stadium, `square` for the smaller rounded corner.
</SlintProperty>

### checkable
<SlintProperty propName="checkable" typeName="bool">
Whether the button toggles between a checked and an unchecked state when clicked.
</SlintProperty>

### checked
<SlintProperty propName="checked" typeName="bool" propertyVisibility="in-out">
Whether the button is currently checked.
The container shape and colors animate when it changes.
</SlintProperty>

### checked-icon
<SlintProperty propName="checked-icon" typeName="image">
The icon image displayed while the button is checked; defaults to `icon`.
</SlintProperty>

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
Whether the button is enabled and can be interacted with.
</SlintProperty>

### enforce-touch-target
<SlintProperty propName="enforce-touch-target" typeName="bool" defaultValue="true">
Whether the button extends its touch target to at least 48px when its visual container is smaller.
</SlintProperty>

### icon
<SlintProperty propName="icon" typeName="image">
The icon image displayed on the button.
</SlintProperty>

### size
<SlintProperty propName="size" typeName="enum" enumName="MaterialButtonSize" defaultValue="MaterialButtonSize.small">
The size bucket, from `extra-small` (32px) through `extra-large` (136px).
</SlintProperty>

### tooltip
<SlintProperty propName="tooltip" typeName="string">
A tooltip text that appears when hovering over the button.
</SlintProperty>

### width-option
<SlintProperty propName="width-option" typeName="enum" enumName="IconButtonWidth" defaultValue="IconButtonWidth.uniform">
The container width bucket: `narrow`, `uniform`, or `wide`.
</SlintProperty>

## Callbacks

### clicked()
Invoked when the button is clicked.
