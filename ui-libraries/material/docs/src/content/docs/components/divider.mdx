A divider is a thin line that groups content in lists and layouts. It provides visual separation between different sections or items in your interface.

## Components

### HorizontalDivider
A horizontal line that spans the full width of its container — `HorizontalDivider` in `Divider.kt` upstream.

### VerticalDivider
A vertical line that spans the full height of its container — `VerticalDivider` in `Divider.kt` upstream.

### Divider
Deprecated alias for `HorizontalDivider`, matching the upstream `Divider` deprecation (`ReplaceWith("HorizontalDivider(modifier, thickness, color)")`).

## HorizontalDivider / VerticalDivider Properties

### thickness
<SlintProperty propName="thickness" typeName="length" defaultValue="DividerTokens.thickness">
The thickness of the divider line — `1px` by default. `0` or a negative value draws a single physical pixel regardless of the display's scale factor, matching the upstream `Dp.Hairline`.
</SlintProperty>

### color
<SlintProperty propName="color" typeName="color" defaultValue="DividerTokens.color">
The color of the divider line — `MaterialPalette.outline_variant` by default.
</SlintProperty>

## Usage

Dividers are commonly used to:
- Separate sections in lists and forms
- Group related content in navigation components
- Provide visual hierarchy in complex layouts
- Create clear boundaries between different interface areas
