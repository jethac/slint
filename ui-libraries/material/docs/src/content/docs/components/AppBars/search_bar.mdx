`SearchBar` is a 56dp pill-shaped search field on
`surface-container-high`. The `expanded` property plays the role of
`SearchBarState.isExpanded`: setting it (or clicking the bar) opens the
expanded surface chosen by `expansion`, and
`expanded-fraction` mirrors `currentTransitionAnimationProgress` — animated
with the active motion scheme's fast-spatial spring, disabled under reduced
motion.

The `expansion` variants map to the pinned expanded composables:

- `docked` → `ExpandedDockedSearchBar`
- `docked-with-gap` → `ExpandedDockedSearchBarWithGap`
  (`dropdown-gap-size`, 2dp default)
- `full-screen` → `ExpandedFullScreenSearchBar` (72dp header)
- `full-screen-contained` → `ExpandedFullScreenContainedSearchBar`
  (contained colors, rounded corners)
- `none` → collapsed bar only

The four expanded overlays are also exported standalone —
`ExpandedDockedSearchBar`, `ExpandedDockedSearchBarWithGap`,
`ExpandedFullScreenSearchBar`,
`ExpandedFullScreenContainedSearchBar` — for layouts that place them
independently of a `SearchBar`. `AppBarWithSearch` embeds a `SearchBar` in a
single-row top app bar with a navigation icon and action buttons and colors
from `SearchBarDefaults.appBarWithSearchColors`.

Deprecated at the pin and mapped here: `TopSearchBar` → `AppBarWithSearch`;
the `SearchBar(query, onQueryChange, …)`/`DockedSearchBar` query-state
overloads → the `expanded`/`text` state properties.

## Properties

### text
<SlintProperty propName="text" typeName="string">
The query text (in-out).
</SlintProperty>

### expanded
<SlintProperty propName="expanded" typeName="bool">
`SearchBarState.isExpanded` — opens/closes the expanded surface (in-out).
</SlintProperty>

### expansion
<SlintProperty propName="expansion" typeName="enum" enumName="SearchBarExpansion">
Which expanded surface the bar opens.
</SlintProperty>

### items
<SlintProperty propName="items" typeName="struct" structName="ListItem">
Result rows shown in the expanded surface.
</SlintProperty>

### expanded-width / expanded-height
<SlintProperty propName="expanded-width" typeName="length">
Outer size of the expanded surface — size `full-screen*` variants to the
window.
</SlintProperty>

## Callbacks

### accepted(text) / edited(text)
Invoked when the query is submitted or edited.

### item-activated(index) -> bool
Invoked when a result row is activated; return true to keep the entered
text.

### action-button-clicked(index)
Invoked when a result row's action icon is clicked.
