`BottomAppBar` displays navigation and key actions in an 80dp bar at the
bottom of the screen, with an optional floating action button at the end.
`FlexibleBottomAppBar` is the Expressive variant — a 64dp row of
`AppBarItem`s with a configurable arrangement.

Set `exit-always` and bind `scroll-position` to `-flickable.content-y` to
slide the bar away while scrolling down and back while scrolling up
(`ExitAlwaysScrollBehavior`); releasing a partial offset snaps the bar with
the active motion scheme's fast-spatial spring
(`BottomAppBarDefaults.snapAnimationSpec`).

export component Example inherits Window {

            items: [
                { icon: Icons.edit, label: "Edit", enabled: true },

    }
}

## AppBarRow and AppBarColumn

`AppBarRow` and `AppBarColumn` arrange `AppBarItem`s in a sequence and move
the ones that do not fit — or that exceed `max-item-count` — into an
overflow menu opened by the trailing `AppBarOverflowIndicator`, like
Compose's `OverflowMeasurePolicy`. The Slint model API cannot derive one
model from another, so callers provide the same entries once as
`AppBarItem`s (`items`) and once as `MenuItem`s (`overflow-items`); the
leading `visible-count` menu entries are hidden.

## Properties

### icon-buttons
<SlintProperty propName="icon-buttons" typeName="struct" structName="IconButtonItem">
`BottomAppBar` action icons.
</SlintProperty>

### items
<SlintProperty propName="items" typeName="struct" structName="AppBarItem">
`FlexibleBottomAppBar`/`AppBarRow`/`AppBarColumn` entries.
</SlintProperty>

### arrangement
<SlintProperty propName="arrangement" typeName="enum" enumName="BottomAppBarArrangement">
`start`, `space-between` (the Expressive default), or `spaced`
(`DockedToolbarTokens.container-max-spacing` between items).
</SlintProperty>

### exit-always
<SlintProperty propName="exit-always" typeName="bool">
Enables the scroll-driven collapse.
</SlintProperty>

### scroll-position
<SlintProperty propName="scroll-position" typeName="length">
The scrolled amount of the content; bind `-flickable.content-y`.
</SlintProperty>

## Callbacks

### fab-clicked()
Invoked when the floating action button is clicked.

### icon-button-clicked(index) / item-clicked(index)
Invoked when a bar action is clicked.

### item-checked-changed(index, checked)
Invoked when a toggleable item's state changes.
