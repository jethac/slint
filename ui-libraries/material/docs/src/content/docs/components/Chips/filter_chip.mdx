A `FilterChip` is a chip that can be toggled on and off to filter content. When selected, it displays a checkmark icon and changes its appearance to indicate the active state.

<CodeSnippetMD imagePath="/src/assets/generated/filterchip-elevated.png" scale="3" imageWidth="460" imageHeight="140" imageAlt="">
```slint
import { FilterChip, ElevatedFilterChip } from "@material";
export component Example inherits Window {
    width: 440px;
    height: 120px;
    background: transparent;
    HorizontalLayout {
        padding: 40px;
        spacing: 20px;
        alignment: center;
        FilterChip {
            checked: true;
            text: "Flat";
        }
        ElevatedFilterChip {
            checked: true;
            text: "Elevated";
        }
        FilterChip {
            checked: true;
            expressive: true;
            text: "Expressive";
        }
    }
}
```
</CodeSnippetMD>

The `ElevatedFilterChip` variant rests at elevation level 1 and lifts to level 3 on drag. With `expressive` enabled, the container's corners morph on selection and press using the active motion scheme's spatial springs.

## Properties

### checked
<SlintProperty propName="checked" typeName="bool" propertyVisibility="in-out">
Whether the filter chip is in the checked (active) state.
</SlintProperty>

### chip-shapes
<SlintProperty propName="chip-shapes" typeName="MaterialChipShapes" defaultValue="FilterChipTokens shapes">
The corner shapes the container morphs between when `expressive` is enabled: `shape` (rest), `selected-shape`, and `pressed-shape`.
</SlintProperty>

### container-shape
<SlintProperty propName="container-shape" typeName="MaterialCornerShape" defaultValue="FilterChipTokens.container-shape">
The static corner shape of the chip container, used when `expressive` is disabled.
</SlintProperty>

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
Whether the chip is enabled and can be interacted with.
</SlintProperty>

### expressive
<SlintProperty propName="expressive" typeName="bool" defaultValue="false">
Whether the container corners morph between the `chip-shapes` on selection and press.
</SlintProperty>

### has-focus
<SlintProperty propName="has-focus" typeName="bool">
Whether the component has focus.
</SlintProperty>

### icon
<SlintProperty propName="icon" typeName="image">
An optional icon displayed on the chip, shown while unchecked.
</SlintProperty>

### text
<SlintProperty propName="text" typeName="string">
The text label displayed on the chip.
</SlintProperty>

### tooltip
<SlintProperty propName="tooltip" typeName="string">
A tooltip text that appears when hovering over the chip.
</SlintProperty>

## Callbacks

### clicked()
Invoked when the chip is clicked.

## Functions

### clear-focus()
Clears the focus from the component.

### focus()
Focuses the component.
