A `CheckBox` is a control that allows users to select one or more options from a set. The box is a
20px rounded square with a check path that draws in when the state turns on; a focused box shows
the 25%-radius inset ring, and hover or press shows the state-layer disc. `CheckBox` toggles
between unchecked and checked; `TriStateCheckbox` cycles unchecked → partially checked → checked
and draws the partially-checked check mark instead.

## Properties

### check-state
<SlintProperty propName="check-state" typeName="enum" enumName="CheckState" propertyVisibility="in-out">
The current state of the checkbox. Can be `unchecked`, `partially-checked`, or `checked`. If the state is `partially-checked`, the tristate property is set to true.

```slint no-test "check-state: CheckState.checked;"
CheckBox {
    check-state: CheckState.checked;
}
```
</SlintProperty>


### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
Whether the checkbox is enabled and can be interacted with.
</SlintProperty>

### enforce-touch-target
<SlintProperty propName="enforce-touch-target" typeName="bool" defaultValue="true">
Whether the checkbox extends its touch target to at least 48px when its visual container is smaller.
</SlintProperty>

### has-error
<SlintProperty propName="has-error" typeName="bool">
Whether the checkbox should display an error state.
</SlintProperty>

### tristate
<SlintProperty propName="tristate" typeName="bool">
Whether the checkbox supports three states (unchecked, partially checked, checked).
</SlintProperty>

## Callbacks

### checked-state-changed(check-state: CheckState)
Invoked when the checkbox state changes.

## Functions

### toggle()
Toggles the checkbox state. In tristate mode, cycles unchecked → checked → partially checked → unchecked.

### set-check-state(check-state: CheckState)
Sets the checkbox state without cycling. Kept for backward compatibility.

## TriStateCheckbox

A `TriStateCheckbox` shares the `CheckBox` API but always operates in tristate mode: clicking
cycles unchecked → checked → partially checked → unchecked, and the `partially-checked` state
draws the indeterminate check mark.

```slint no-test "check-state: CheckState.partially-checked;"
TriStateCheckbox {
    check-state: CheckState.partially-checked;
}
```
