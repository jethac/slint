Use a `Slider` to select a single value from a continuous or stepped
range — volume, brightness, or any scalar setting. The handle is a
pill that narrows while pressed, dragged or focused; `VerticalSlider`
runs the same widget top to bottom (set `top-to-bottom: false` for a
bottom-to-top direction), and `RangeSlider` selects a range between
two thumbs.

<CodeSnippetMD imagePath="/src/assets/generated/slider-sizes.png" scale="3" imageWidth="400" imageHeight="280" imageAlt="">
```slint
import { Slider, MaterialSliderSize } from "@material";
export component Example inherits Window {
    width: 380px;
    height: 260px;
    background: transparent;
    VerticalLayout {
        padding: 20px;
        spacing: 8px;
        for s in [MaterialSliderSize.extra-small, MaterialSliderSize.small, MaterialSliderSize.medium, MaterialSliderSize.large, MaterialSliderSize.extra-large]: Slider {
            value: 0.4;
            size: s;
            width: parent.width;
        }
    }
}
```
</CodeSnippetMD>

`size` picks the track preset from `extra-small` (16px track) through
`extra-large` (96px). `steps` snaps the value to that many discrete
stops and draws tick marks; `centered` runs the active track from the
track's center instead of the leading edge.

## Properties

### value
<SlintProperty propName="value" typeName="float" propertyVisibility="in-out">
The selected value, coerced into `minimum..maximum`.
</SlintProperty>

### minimum
<SlintProperty propName="minimum" typeName="float" defaultValue="0">
The value range's lower bound — `SliderState.valueRange` upstream.
</SlintProperty>

### maximum
<SlintProperty propName="maximum" typeName="float" defaultValue="1">
The value range's upper bound.
</SlintProperty>

### steps
<SlintProperty propName="steps" typeName="int" defaultValue="0">
The number of discrete stops between `minimum` and `maximum`. Ticks are
drawn for every stop, including the endpoints.
</SlintProperty>

### size
<SlintProperty propName="size" typeName="enum" enumName="MaterialSliderSize" defaultValue="MaterialSliderSize.extra-small">
The track preset, `extra-small` through `extra-large`.
</SlintProperty>

### centered
<SlintProperty propName="centered" typeName="bool" defaultValue="false">
`SliderDefaults.CenteredTrack` — the active track starts at the center
of the track, for bipolar values.
</SlintProperty>

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
Whether the slider can be interacted with. Disabled sliders render with
the disabled color table.
</SlintProperty>

### enforce-touch-target
<SlintProperty propName="enforce-touch-target" typeName="bool" defaultValue="true">
Enforce the 48px minimum interactive size — `minimumInteractiveComponentSize` upstream.
</SlintProperty>

### top-to-bottom
<SlintProperty propName="top-to-bottom" typeName="bool" defaultValue="true">
`VerticalSlider` only: values grow top to bottom when set, bottom to
top otherwise.
</SlintProperty>

### mirror
<SlintProperty propName="mirror" typeName="bool" defaultValue="false">
`state.isRtl` upstream — mirror the track axis for right-to-left
layouts.
</SlintProperty>

### icon-active-start / icon-active-end / icon-inactive-start / icon-inactive-end
<SlintProperty propName="icon-active-start" typeName="image">
Inset icons inside the track — `trackIcon{Active,Inactive}{Start,End}`
in the Material Views spec. Sizes `medium` and up reserve an icon
region; an icon shows only when the region fits `icon-size + 2·padding`.
</SlintProperty>

### icon-active-color / icon-inactive-color
<SlintProperty propName="icon-active-color" typeName="color">
The tint for the inset icons on the active track and on the inactive
container.
</SlintProperty>

### label-behavior
<SlintProperty propName="label-behavior" typeName="enum" enumName="MaterialSliderLabelBehavior" defaultValue="MaterialSliderLabelBehavior.floating">
The value indicator: `floating` shows it during interaction,
`within-bounds` always, `gone` never — `Slider_labelBehavior` in Views.
</SlintProperty>

### thumb-track-gap
<SlintProperty propName="thumb-track-gap" typeName="length" defaultValue="SliderTokens.active-handle-leading-space">
`thumbTrackGapSize` — the gap the track leaves around the handle.
</SlintProperty>

### track-corner-override
<SlintProperty propName="track-corner-override" typeName="length" defaultValue="-1px">
`trackCornerSize` — an explicit corner radius takes the pin's
corner-shrinking path; `-1px` resolves to the `size` preset's corner.
</SlintProperty>

### has-focus / pressed / focused / interacting
<SlintProperty propName="has-focus" typeName="bool" propertyVisibility="out">
Read-only interaction state. `interacting` is the pin's
`interactions.isNotEmpty()` — press, drag and focus, not hover.
</SlintProperty>

## Callbacks

### released(value: float)
`onValueChangeFinished` — on pointer release and on key-up of a
navigation key.

### value-changed(value: float)
`onValueChange` — the value the interaction set.

## RangeSlider

`RangeSlider` selects a range between `start-value` and `end-value`
over the same `minimum..maximum` range. Taps move the nearer thumb,
drags cannot cross the other thumb, and each thumb has its own focus,
keyboard control and accessibility semantics. Its `value-changed` and
`released` callbacks report `(start, end)` pairs.

## Functions

### set-value(v: float)
Sets `value`, coerced into `minimum..maximum` — the same path the
`accessible-action-set-value` handler uses.

### increment-value() / decrement-value()
Move `value` by one step (`steps > 0`) or one percent of the range —
the keyboard arrows and `accessible-action-increment`/`decrement` path.
