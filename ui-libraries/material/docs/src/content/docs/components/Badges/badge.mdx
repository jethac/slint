A `Badge` is a small status indicator anchored to another component — `Badge` and `BadgedBox` in `Badge.kt` upstream. Empty `text` draws the small 6px dot; any text draws the large badge, exactly the upstream `content == null` branch.

## Badge Properties

### text
<SlintProperty propName="text" typeName="string">
The count or label inside the badge — upstream's `content` slot. Leave empty for the dot.
</SlintProperty>

### container_color
<SlintProperty propName="container_color" typeName="color" defaultValue="BadgeTokens.color">
The badge background — upstream's `containerColor`, `BadgeTokens.color` (`error`).
</SlintProperty>

### content_color
<SlintProperty propName="content_color" typeName="color" defaultValue="content-color-for(container-color)">
The text color — upstream's `contentColor`, `ColorScheme.contentColorFor(containerColor)` (`on_error` for the default error container) falling back to `LocalContentColor.current` (`on_background` stands in for it).
</SlintProperty>

## BadgedBox

`BadgedBox` wraps the anchor content (usually an `Icon`) and overlaps the badge at its top end corner — a dot sits `BadgeOffset` (6px) from the end/top edge, a content badge `BadgeWithContentHorizontalOffset` (12px) from the end with `BadgeWithContentVerticalOffset` (14px) of overlap, the offset table in Badge.kt. The badge never contributes to the layout: the box takes the anchor's size.

```slint
BadgedBox {
    badge_text: "12";
    badge_visible: unread-count > 0;
    Icon { source: Icons.menu; width: 24px; height: 24px; }
}
```

### badge_text
<SlintProperty propName="badge_text" typeName="string">
Forwarded to the badge's `text`.
</SlintProperty>

### badge_visible
<SlintProperty propName="badge_visible" typeName="bool" defaultValue="true">
Show or hide the badge without removing it — upstream expresses this with a conditional `badge` slot.
</SlintProperty>

### badge_container_color / badge_content_color
<SlintProperty propName="badge_container_color" typeName="color" defaultValue="BadgeTokens.color">
Forwarded to the badge's `container_color`/`content_color`.
</SlintProperty>

Upstream places the badge with `placeRelative`, mirroring under RTL; Slint has no RTL, so the badge always anchors to the top right. Upstream's `badgeBounds()` modifier clamps the badge inside a parent's icon bounds and is applied only by the navigation items and `Tab` — since `BadgedBox` here wraps the anchor directly, the geometry is already the same.

## Accessibility

`Badge` adds no semantics of its own, like upstream — the badge counts toward the description of its anchor. Set `accessible-label` on the anchored component (`Icon`, `IconButton`, or navigation item) so the count is announced.
