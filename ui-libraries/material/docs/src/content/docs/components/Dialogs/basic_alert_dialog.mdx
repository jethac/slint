A `BasicAlertDialog` is the upstream basic `AlertDialog` overload: a modal overlay that centers arbitrary content in a
box sized between 280 and 560&nbsp;dp — `sizeIn(DialogMinWidth, DialogMaxWidth)` intersected with the space the
dialog is offered. Unlike `Dialog` it draws no surface of its own and adds no padding, so callers supply their own
container, spacing, and actions. It is the base for content that does not fit the icon/title/text pattern.

## Callbacks

### dismissed()
Invoked when the scrim is clicked or Escape is pressed — the upstream `onDismissRequest`. Call `close()` from
the callback (or leave the dialog open) as appropriate.
