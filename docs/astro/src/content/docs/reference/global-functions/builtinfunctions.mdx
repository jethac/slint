## animation-tick() -> duration

This function returns a monotonically increasing time, which can be used for animations.
Calling this function from a binding will constantly re-evaluate the binding.
It can be used like so: `x: 1000px + sin(animation-tick() / 1s * 360deg) * 100px;` or `y: 20px * mod(animation-tick(), 2s) / 2s `

```slint playground
export component Example inherits Window {
    preferred-width: 100px;
    preferred-height: 100px;

    Rectangle {
        y:0;
        background: red;
        height: 50px;
        width: parent.width * mod(animation-tick(), 2s) / 2s;
    }

    Rectangle {
        background: blue;
        height: 50px;
        y: 50px;
        width: parent.width * abs(sin(360deg * animation-tick() / 3s));
    }
}
```

## inherit(property-name, fallback)

Read a property from the nearest ancestor element that defines it.
The property name must be a string literal.
The fallback determines the result type and applies when no ancestor provides a value.
Ancestor values must convert to that type.
Changes to the ancestor property update bindings that consume it.

The lookup starts at the parent of the element containing the expression.
It follows the rendered component hierarchy, including child slots, reusable components, and repeaters.
Each component instance receives its enclosing context independently.
Explicit bindings override inherited defaults through normal property precedence.

Unlike CSS's standalone `inherit` value, this function names the property and supplies a typed fallback.
Use it for scoped styling or other reactive context values.
Global components have no ancestor scope and cannot call `inherit`.

```slint
component Label inherits Text {
    color: inherit("content-color", #000000);
}

export component Example inherits Window {
    Rectangle {
        in property <color> content-color: #6750a4;
        Label { text: "Inherited color"; }
    }
}
```

## debug(...)

The debug function can take one or multiple values as arguments, prints them, and returns nothing.
